# Netflix Business Insights

## Project Overview
This project explores Netflix content data to identify trends in movies, TV shows, genres, countries, release years, and content duration.

## Objectives
- Clean and prepare the dataset.
- Perform exploratory data analysis (EDA).
- Create meaningful data visualizations.
- Identify content trends and patterns.
- Present actionable business insights.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Key Findings
- Movies represent 69.69% of the dataset.
- TV shows represent 30.31%.
- The United States has the highest country-associated title count in the analysis.
- International Movies and Dramas are frequently listed genres.
- The median movie duration is 98 minutes.

## Project Files
- `Netflix_EDA.ipynb` — analysis and visualizations
- `Netflix_Business_Insights_Report.docx` — final analytical report
- `screenshots/` — project evidence
